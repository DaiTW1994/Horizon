### [Asahi Linux 官方支持 Apple M3](https://asahilinux.org/2026/09/m2-episode-1/) ⭐️ 8.0/10

Asahi Linux 项目宣布对 Apple M3 芯片提供官方支持，使 Linux 可以在较新的 M3 版 Mac 上运行。这是 Apple Silicon 开源硬件支持的重要进展，为 Linux-on-ARM 社区和关注开放硬件生态的用户扩展了可用设备范围。公告本身没有提供详细的技术说明，相关报道由 Phoronix 以“Asahi Linux Official M3”为题转载。虽然具体安装步骤和内核支持细节尚未公开，但这一支持意味着 M3 用户不再需要依赖实验性的非官方方案。

hackernews · mdp2021 · 9月6日 14:08 · [社区讨论](https://news.ycombinator.com/item?id=49586698)

**「背景」** Asahi Linux 是一个致力于将 Linux 移植到 Apple Silicon 芯片的开源项目，此前已支持 M1 和 M2 系列，但 M3 的官方支持长期缺失。据 Phoronix 报道，Asahi Linux 现已正式支持搭载 M3、M3 Pro 和 M3 Max 的 Mac，安装器中已合并网络摄像头、USB 3、Wi-Fi 和 AV1 解码等支持；不过 GPU 驱动仍不完善，且因 DCP（显示控制器）支持缺失，睡眠和 HDMI 功能尚不可用，M3 Ultra 机型也暂未获得支持。

**「影响」** 最直接的影响是，M3 版 Mac 用户现在有了面向最新 Apple Silicon 的官方 Linux 支持路径，使 Linux 在 Apple 新硬件上的可用性得到实质推进。

**「社区讨论」** 评论者普遍赞赏这一项目，但也指出实际采用障碍包括睡眠与 HDMI 支持不足，以及 M1 Ultra 上运行 llama.cpp 的性能明显不如 Metal 后端。还有人感叹这种逆向工程工作“令人沮丧”，并询问在 MacBook M2 上双启动 macOS 与 Asahi 的最佳方式。

### [Nitter 与 XCancel 在法律咨询后恢复服务](https://github.com/zedeus/nitter/commit/1428b4c2b4246f92a7e5b2673438e5fb39fcc4a3) ⭐️ 7.0/10

开源替代前端 Nitter 与 XCancel 已恢复运行，项目维护者在获得法律建议后作出这一决定。Nitter 作为 X/Twitter 的替代前端，允许用户在不登录或屏蔽广告的情况下浏览内容；XCancel 则提供相关实例的清单。此次恢复对依赖这些服务的用户意义重大，尤其是在 X 平台信息不可替代的背景下。目前官方公告未提供更多细节，后续走向仍待观察。

hackernews · zImPatrick · 9月6日 17:49 · [社区讨论](https://news.ycombinator.com/item?id=49588988)

**「背景」** Nitter 是一个免费开源的非官方 Twitter/X 前端，旨在无需登录或追踪即可浏览推文；XCancel 则是基于 Nitter 的另一个前端服务。此前，X Corp 曾向 Nitter 及其实例发送停止函，指控其抓取数据并要求永久关闭，导致 Nitter 与 XCancel 一度停止服务。现在，两者在收到法律建议后恢复运营，这一动态对依赖替代前端的用户和开源社区具有重要意义。

### [DNS 沦为诈骗温床：大量新域名被用于欺诈](https://simonwillison.net/2026/Sep/6/the-purpose-of-dns-is-to-spread-scams/) ⭐️ 7.0/10

西蒙·威利森引用特伦斯·伊登的文章指出，域名系统（DNS）已成为犯罪分子大规模行骗的渠道。根据 Interisle 报告，2025 年通用顶级域（gTLD）新增注册约 8500 万个，其中到 2025 年 5 月已有 850 万个被加入屏蔽名单。伊登认为 10% 只是滥用率的下限，实际可能接近 20%，即每五个新注册的 gTLD 域名中就有一个用于诈骗。文章还提到，ICANN 多年来一直在讨论这一问题，但情况依然严峻。

rss · Simon Willison · 9月6日 14:40

**「背景」** DNS 是互联网的基础设施，负责将域名解析为 IP 地址，使用户能够访问网站。通用顶级域（如 .com、.net）由注册商批量销售，注册门槛低且流程自动化，容易被攻击者利用来快速建立钓鱼、诈骗和恶意软件传播站点。防守方通常依靠域名屏蔽名单来应对滥用，但单纯屏蔽并不能解决根因。

**「影响」** 新注册域名的高滥用率意味着依赖 DNS 的网站访问、邮件服务和链接安全都面临更高的欺诈风险，安全团队需要加强实时信誉评估和注册验证机制。

telegram · zaihuapd · 9月6日 06:13

**「影响」** OpenAI 在发布后反复修改 GPT-6 Astra 及其他模型的评测数据，可能削弱开发者、研究者和安全评估人员对官方基准数字的信任，使其在模型选型或横向比较时难以依据这些指标作出可靠判断。这一做法也引发了对 OpenAI 基准报告透明度的质疑，但尚不能据此推断其模型的真实性能优劣。
